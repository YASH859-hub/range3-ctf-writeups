# Screenshot evidence

Screenshots are extracted from the five user-provided Word reports and kept in challenge-specific subdirectories. Filenames are ordered and descriptive; each is referenced inline from its Markdown report.

For public sharing, M2 default lab credentials and other selected credential/private-key/API-key values have been covered in the evidence copies. This preserves the screenshot while avoiding publication of lab secrets. Do not replace these sanitized evidence copies with unredacted originals.
